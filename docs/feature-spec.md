# feature-spec.md

## 0. 文档用途
本文件描述平台要实现的功能。AI 在开发任何功能前必须先读本文件，确认范围、输入输出和验收标准。功能范围以本文件为准，不得自行扩展或简化。

## 1. 角色与权限
- 游客：浏览登录/注册页
- 普通用户：默写练习、词书浏览、错词本、个人数据、个人设置
- 管理员：词书管理、单词导入、用户管理、数据概览

规则：用户端接口需登录；/admin/* 需 role == "admin"；被禁用用户不得登录。

## 2. 功能清单
P0：F1 注册登录、F2 创建词书、F3 导入单词、F4 开始默写、F5 判分反馈、F6 错词本
P1：F7 掌握度与进度、F8 错词重练、F9 数据看板、F10 用户管理
P2：F11 发音播放、F12 导入进度、F13 数据概览
预留：F14 AI 英语对话（本期不实现）

## 3. 功能详细说明

### F1 注册与登录
输入：注册 username/email/password；登录账号+密码。
规则：username、email 唯一；密码≥8位且哈希存储；登录返回 token 与用户信息（不含密码）。
异常：重复注册 409；密码错 401；禁用 403。

### F2 管理员创建词书
输入：name（必填）、description、level。
规则：默认 draft，可 published/archived；仅 published 对用户可见。
删除规则：词书下无单词时可正常删除；存在单词时返回 409，必须先清空词书内单词，不支持 force 级联删除。

### F3 管理员导入单词
输入：目标词书 id、Excel/CSV（spelling 必填，其余可选）。
要求：先返回解析预览；逐行校验空/重复/超长；确认后导入；返回成功失败行数与失败明细；大文件后台任务不阻塞。
验收：部分失败不影响合法行入库；失败可定位行号；同词书不重复 spelling。

### F4 用户选择词书开始默写
输入：wordbook_id、题数（默认20，可选10/20/50）、strict_mode（默认 true，落库到 practice_sessions）。
规则：优先未掌握词，少量混入已掌握复习；顺序可随机；出题接口不得返回拼写。
每题展示：音标（英美可切换）、中文释义、词性；出题 hint 仅返回 length，首字母提示为后续接口功能。
验收：题目无拼写字段；词数不足按实际出题并提示；空词书不可开始。

### F5 默写判分与即时反馈
输入：session_id、word_id、user_input、used_hint。
规则：忽略大小写与首尾空格；默认严格比对；英美拼写均判正确；可选宽松模式忽略连字符/空格。
反馈：正确墨绿对勾+例句；错误朱红标记+正确拼写+加入错词本；就地呈现不弹窗；回车进入下一题。
验收：大小写空格不影响判分；color/colour 均正确；答错才返回拼写；重复提交不重复计分。

### F6 错词本自动生成
规则：答错自动入错词本；同词累加次数不重复建条；支持查看移除；普通练习与错词重练均适用：连续正确 2 次即标记 resolved=true，再次答错重置 resolved=false。
验收：答错立即出现；无重复记录；移除后可再入。

### F7 掌握度与词书进度
分级：0 新词 / 1 学习中 / 2 已掌握。
规则：连续正确2次升已掌握；答错降学习中；进度=已掌握/总词数。

### F8 错词专项重练
规则：只出 resolved=false 的词；题数不超错词数；结果同样更新掌握度与错词状态；连续正确 2 次即 resolved=true（普通练习同样适用），再次答错重置为 false。
验收：错词本为空不可开始并提示；重练达标后从错词本消失。

### F9 个人数据看板
指标：累计默写数、总体正确率、连续学习天数、已掌握词数、近7/30天趋势。
验收：数据一致；断签归零；无数据展示鼓励文案。

### F10 管理员用户管理
能力：列表分页搜索筛选；禁用/启用；重置密码；查看单个用户学习数据。
验收：禁用后无法登录；不返回密码哈希；普通用户访问管理接口 403。

### F11 发音播放
规则：优先词库音频；无音频用系统语音合成；系统语音不可用时回退浏览器 TTS；支持英美切换。
验收：无音频不报错；切换音标发音同步。

### F12 导入任务进度
展示：状态 pending/processing/done/failed；总数/成功/失败；失败行列表（行号、内容、原因）。
验收：状态可查；失败可定位。

### F13 管理员数据概览
指标：总用户数、活跃用户数、总词书数、总单词数、今日练习次数与答题量。
验收：聚合查询无明显性能问题。

## 4. 关键交互约束（全局）
- 列表接口必须分页
- 写操作必须有成功/失败反馈
- 练习页禁用提交防重复
- 判分与答案逻辑只在服务端
- 空状态、错误态、加载态必须实现
- 桌面端与移动端都要可用

## 5. 验收总则
每个功能交付须说明：实现了哪些接口/页面/组件；对照本文档哪些验收点已满足；未实现或取舍部分及原因。

## 6. AI 英语对话

### F14 AI 英语对话练习

状态：2026-10-24 已实现基础对话能力，原“仅预留、不实现对话逻辑”的范围已被取代。

已实现：
- `/api/v1/agent/chat` SSE 流式对话（Router + Skill 分发）
- 会话与消息持久化：`/api/v1/ai/sessions` 列表 / 创建 / 详情 / 删除
- 用户端 `/ai-chat`：会话侧栏、流式输出、停止生成、场景选择、历史重载
- 管理端用户数据抽屉内生成学情画像
- 未配置模型时使用 Mock 客户端，链路可完整跑通

仍未实现：
- 对话中标记生词并加入错词本
- 朗读 AI 回复
- 对话评分
- 真实模型服务的端到端验收

接口与响应细节见 `docs/api-contract.md`；验收结论见 `docs/acceptance-checklist.md`。

## 7. 管理端 MCP 服务

### F15 管理端 MCP 服务

状态：2026-10-28 实现 v1。

能力：
- 以 MCP Streamable HTTP 形式挂载在 `POST /mcp`，复用管理员 JWT 鉴权。
- 管理端「MCP 接入」页可创建长期客户端令牌：只读 / 可提交变更两种权限，可选有效期，可随时吊销。
- 只读工具：数据概览、用户列表、用户统计、词书列表、单词列表、导入任务状态。
- 写工具只生成 `mcp_change_requests` 待审批申请，不会直接修改业务数据。
- 写范围：词书增删改、单词增删改、批量导入、用户启用/禁用、学情画像刷新。

规则：
- MCP 请求可携带 `Bearer mcp_...` 长期令牌，或管理员 JWT；客户端令牌只保存 SHA-256 哈希。
- 只读令牌不能调用任何写提案工具；可提交变更令牌也只能创建待审批申请。
- 每个 MCP 请求都必须携带 `Authorization: Bearer <管理员 JWT>`，角色以数据库 `users.role` 为准。
- 写申请由管理员在 `/admin/mcp/approvals` 页面人工确认后执行；审批前可驳回，默认 30 分钟过期。
- 审批使用条件更新防止并发重复执行；执行失败记录 `failed` 与错误信息。
- 重置密码不通过 MCP 开放。
- 工具调用、提案、审批、驳回均写入 `mcp_audit_logs`，密码、令牌与文件内容脱敏。
- 批量导入文件暂存在 `mcp_import_uploads`，大小上限沿用现有导入限制（10MB）。

验收：
- 未携带令牌返回 401，普通用户令牌返回 403，管理员令牌可完成握手。
- 长期客户端令牌创建后只显示一次明文，列表与数据库只保留前缀和哈希。
- 只读令牌调用写提案工具被拒绝；可写令牌调用后仍只生成 pending 申请。
- 吊销或过期令牌立即返回 401。
- 写工具调用后业务数据不变，仅新增 pending 申请。
- 审批通过后数据真实写入，重复审批返回 409。
- 驳回、过期、取消都不会执行业务写入。
- 导入审批后创建后台任务并返回任务 id，失败行沿用现有导入明细。
- 审计表可按管理员与时间检索，且不含敏感参数。

接口与工具清单见 `docs/api-contract.md`，客户端接入见 `docs/mcp-client.md`。
