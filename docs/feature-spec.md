# feature-spec.md

## 0. 文档用途
本文件描述平台要实现的功能。AI 在开发任何功能前必须先读本文件，确认范围、输入输出和验收标准。功能范围以本文件为准，不得自行扩展或简化。

## 1. 角色与权限
- 游客：浏览登录/注册页
- 普通用户：默写练习、词书浏览、错词本、个人数据、个人设置
- 管理员：词书管理、单词导入、用户管理、数据概览

规则：用户端接口需登录；/admin/* 需 role == "admin"；被禁用用户不得登录。

## 2. 功能清单
P0：F1 注册登录、F2 创建词书、F3 导入单词、F4 开始默写、F5 判分反馈、F6 错词本
P1：F7 掌握度与进度、F8 错词重练、F9 数据看板、F10 用户管理
P2：F11 发音播放、F12 导入进度、F13 数据概览
预留：F14 AI 英语对话（本期不实现）

## 3. 功能详细说明

### F1 注册与登录
输入：注册 username/email/password；登录账号+密码。
规则：username、email 唯一；密码≥8位且哈希存储；登录返回 token 与用户信息（不含密码）。
异常：重复注册 409；密码错 401；禁用 403。

### F2 管理员创建词书
输入：name（必填）、description、level。
规则：默认 draft，可 published/archived；仅 published 对用户可见。

### F3 管理员导入单词
输入：目标词书 id、Excel/CSV（spelling 必填，其余可选）。
要求：先返回解析预览；逐行校验空/重复/超长；确认后导入；返回成功失败行数与失败明细；大文件后台任务不阻塞。
验收：部分失败不影响合法行入库；失败可定位行号；同词书不重复 spelling。

### F4 用户选择词书开始默写
输入：wordbook_id、题数（默认20，可选10/20/50）。
规则：优先未掌握词，少量混入已掌握复习；顺序可随机；出题接口不得返回拼写。
每题展示：音标（英美可切换）、中文释义、词性、可选提示（首字母/字母数，使用即标记）。
验收：题目无拼写字段；词数不足按实际出题并提示；空词书不可开始。

### F5 默写判分与即时反馈
输入：session_id、word_id、user_input、used_hint。
规则：忽略大小写与首尾空格；默认严格比对；英美拼写均判正确；可选宽松模式忽略连字符/空格。
反馈：正确墨绿对勾+例句；错误朱红标记+正确拼写+加入错词本；就地呈现不弹窗；回车进入下一题。
验收：大小写空格不影响判分；color/colour 均正确；答错才返回拼写；重复提交不重复计分。

### F6 错词本自动生成
规则：答错自动入错词本；同词累加次数不重复建条；支持查看移除；重练连续正确达阈值标记 resolved。
验收：答错立即出现；无重复记录；移除后可再入。

### F7 掌握度与词书进度
分级：0 新词 / 1 学习中 / 2 已掌握。
规则：连续正确2次升已掌握；答错降学习中；进度=已掌握/总词数。

### F8 错词专项重练
规则：只出 resolved=false 的词；题数不超错词数；结果同样更新掌握度与错词状态。
验收：错词本为空不可开始并提示；重练达标后从错词本消失。

### F9 个人数据看板
指标：累计默写数、总体正确率、连续学习天数、已掌握词数、近7/30天趋势。
验收：数据一致；断签归零；无数据展示鼓励文案。

### F10 管理员用户管理
能力：列表分页搜索筛选；禁用/启用；重置密码；查看单个用户学习数据。
验收：禁用后无法登录；不返回密码哈希；普通用户访问管理接口 403。

### F11 发音播放
规则：优先词库音频；无音频用 TTS 兜底；支持英美切换。
验收：无音频不报错；切换音标发音同步。

### F12 导入任务进度
展示：状态 pending/processing/done/failed；总数/成功/失败；失败行列表（行号、内容、原因）。
验收：状态可查；失败可定位。

### F13 管理员数据概览
指标：总用户数、活跃用户数、总词书数、总单词数、今日练习次数与答题量。
验收：聚合查询无明显性能问题。

## 4. 关键交互约束（全局）
- 列表接口必须分页
- 写操作必须有成功/失败反馈
- 练习页禁用提交防重复
- 判分与答案逻辑只在服务端
- 空状态、错误态、加载态必须实现
- 桌面端与移动端都要可用

## 5. 验收总则
每个功能交付须说明：实现了哪些接口/页面/组件；对照本文档哪些验收点已满足；未实现或取舍部分及原因。

## 6. 预留功能：AI 英语对话（本期不实现）

### F14 AI 英语对话练习（Phase 2）

状态：仅预留接口与入口，不实现对话逻辑。

产品设想：
- 用户与 AI 进行英语自由对话或情景对话
- AI 以英文回复，可附中文提示（可开关）
- 对话中可标记生词并加入错词本
- 可选朗读 AI 回复

本期只做：
- 用户端入口（首页/导航显示，点击提示"即将上线"）
- 后端路由占位：/api/v1/ai/chat 返回 501
- 数据库预留会话表与消息表（可建表，不写业务逻辑）
- 前端预留 API 封装与页面骨架（空状态页）
- 配置项预留：模型服务地址、密钥（走 .env，不硬编码）

本期不做：
- 不接任何大模型
- 不实现对话存储逻辑
- 不做语音识别与合成
- 不做对话评分

接口占位：
- POST /api/v1/ai/chat        → 501
- GET  /api/v1/ai/sessions    → 501
- POST /api/v1/ai/sessions    → 501

预留数据表：
- ai_conversations：id、user_id、title、scene、created_at、updated_at
- ai_messages：id、conversation_id、role(user/assistant)、content、created_at

验收：
- 入口可见但明确标注"即将上线"
- 调用占位接口返回 501 且响应格式符合统一包装
- 不引入任何模型 SDK 依赖
