# 示例词库

`sample-words.csv` 是一份可直接导入的示例词库，共 24 个常见词，用于快速跑通「词书 → 导入 → 默写 → 统计」全流程。

## 导入步骤

1. 使用管理员账号登录，进入「管理端 → 词书管理」，新建一本词书并设为 `published`。
2. 进入该词书，点击「导入」。
3. 上传 `docs/examples/sample-words.csv`。
4. 导入向导会自动识别表头；确认列映射后查看预览与校验结果。
5. 确认导入，等待后台任务完成。
6. 用普通用户账号进入词书架，即可看到这本词书并开始默写。

## 列说明

| 列 | 含义 | 必填 |
|---|---|---|
| `spelling` | 拼写 | 是 |
| `phonetic_uk` | 英式音标 | 否 |
| `phonetic_us` | 美式音标 | 否 |
| `meaning_cn` | 中文释义 | 否 |
| `part_of_speech` | 词性 | 否 |
| `example_en` | 英文例句 | 否 |
| `example_cn` | 例句译文 | 否 |
| `audio_url` | 音频地址 | 否 |
| `sort_order` | 排序，从 0 开始 | 否 |

约定：

- 同一本词书内 `spelling` 不区分大小写，不能重复。
- 文件编码为 UTF-8；导入接口也兼容 GB18030。
- 单文件不超过 10 MB、20000 行。
- 没有 `audio_url` 时，前端会用浏览器 TTS 兜底发音。
