# 四六级词库

三份可直接导入的词库，均为 UTF-8 CSV，表头与 [示例词库](../sample-words.csv) 一致。

| 文件 | 适用场景 | 词数 |
|---|---|---:|
| `cet4-words.csv` | 四级完整大纲词汇 | 4540 |
| `cet6-words.csv` | 六级完整词汇（含四级基础） | 5692 |
| `cet6-new-words.csv` | 六级新增词汇（已掌握四级者可选） | 2168 |

其中六级完整词库 = 四级 4540 词 + 六级新增 2168 词 − 重合 1016 词。

## 数据来源

- **CET-4**：[mahavivo/english-wordlists](https://github.com/mahavivo/english-wordlists) 的 `CET4_edited.txt`，由贵州大学四级大纲词汇表整理。
- **CET-6**：同一仓库的 `CET6_edited.txt`，整理自《全国大学英语四、六级考试大纲》2016 年版。

原始数据为社区整理版本，可能与官方大纲有个别出入；转换时已去重、按字母排序，并剔除少量格式异常或无法解析的条目，因此词数与来源声明略有差异。

## 字段

| 列 | 内容 |
|---|---|
| `spelling` | 拼写 |
| `phonetic_uk` | 音标（来源只提供一套音标，统一放在英式列） |
| `meaning_cn` | 中文释义，多个义项保留原编号 |
| `part_of_speech` | 词性（`a.`/`ad.` 已统一为 `adj.`/`adv.`） |
| `sort_order` | 按字母顺序从 1 递增 |

`phonetic_us`、例句和音频列为空；没有音频时前端优先用后端系统语音合成，失败再回退浏览器 TTS。

## 导入步骤

1. 使用管理员账号登录，进入「管理端 → 词书管理」，新建词书并设为 `published`。
2. 进入该词书，点击「导入」，选择上表中的 CSV 文件。
3. 导入向导会自动识别表头，确认列映射后查看预览与校验结果。
4. 确认导入，等待后台任务完成。
5. 用普通用户账号进入词书架即可开始默写。

建议词书名称：`四级词汇（4540）`、`六级词汇（5692）`、`六级新增词汇（2168）`。
