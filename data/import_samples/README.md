# 词条批量导入样例

本目录提供可直接用于「词书管理 - 词条管理 - 批量导入」的 JSON 文件。
每个文件都是**词条数组**，字段与后端校验器完全一致：

```json
[
  {
    "word": "abandon",
    "phonetic": "/əˈbændən/",
    "translation": "v. 放弃，遗弃",
    "example_en": "They had to abandon the plan for lack of funds.",
    "example_cn": "由于缺乏资金，他们不得不放弃这个计划。"
  }
]
```

## 文件清单

| 文件 | 词数 | 适用场景 |
| :--- | ---: | :--- |
| `gaokao-words.json` | 51 | 高中核心基础词 |
| `cet4-words.json` | 147 | 大学英语四级核心高频词 |
| `cet6-words.json` | 57 | 大学英语六级进阶高频词 |
| `kaoyan-words.json` | 58 | 考研核心词汇 |
| `mixed-100-words.json` | 100 | 四本词书轮流抽取的跨考试精选词 |

## 导入步骤

1. 打开「词书管理」，选择目标词书并进入「词条管理」。
2. 点击「批量导入」，选择本目录下对应的 JSON 文件。
3. 导入前会先校验全部词条；任一条不通过则整批不写入，页面会列出具体字段和条数。
4. 同一词书重复导入同一份文件不会产生重复词条，只会更新已有词条内容。
5. 若目标词书已有相同的词，导入会覆盖五个内容字段并将其恢复为可用状态，不影响用户练习记录。

## 字段规则

- `word`：小写 ASCII 词头，不含首尾空格。
- `phonetic`：必须用 `/ /` 包裹，例如 `/əˈbændən/`。
- `translation`：以词性前缀开头，且包含中文，例如 `v. 放弃，遗弃`。
- `example_en`：必须包含目标词，并以 `.`、`!`、`?` 或 `"` 结尾。
- `example_cn`：不得夹杂英文单词，并以 `。`、`！`、`？` 或 `"` 结尾。
- 单次文件上限 2MB。
