# Skill：实现/修改默写练习页

## 触发场景
练习页的出题、作答、反馈、完成流程。

## 步骤
1. 创建 session，拿到题目列表（只有 id、音标、释义、词性、提示；无拼写）
2. 渲染：音标衬线大字 + 中文释义 + 下划线式输入框
3. 状态机：idle → answering → submitting → submitted(correct/wrong) → next
4. 回车提交；提交中禁用按钮
5. 反馈就地呈现：
   - 正确：墨绿对勾 + 例句
   - 错误：朱红波浪线 + 正确拼写 + 加入错词本
6. 结束调用 finish，展示印章完成页 + 正确率

## 红线
- 前端不得持有答案
- 不用弹窗反馈
- 不出现圆角边框输入框
