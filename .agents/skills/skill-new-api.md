# Skill：新增一个后端接口

## 触发场景
用户要求新增/修改任何 API。

## 步骤
1. 确认输入输出字段，列出请求/响应结构
2. 在 schemas/ 下新建或扩展 Pydantic 模型
3. 在 services/ 实现业务逻辑（判分、统计等不写在路由里）
4. 在 api/v1/ 对应 router 中注册路由，加鉴权依赖
5. 涉及表变更 → 走 skill-db-migration
6. 在 frontend/src/api/ 增加对应封装函数
7. 自检：响应包装、分页格式、状态码、角色校验

## 输出要求
- 说明改了哪些文件
- 给出请求/响应字段表
- 标注鉴权要求（登录 / 管理员）
