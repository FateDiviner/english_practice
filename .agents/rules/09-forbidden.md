# 禁止事项

- 引入未声明依赖
- 硬编码密钥或数据库密码（必须走 .env）
- 省略鉴权与角色校验
- 前端存储或传输单词答案
- 为跑通而注释掉校验、异常处理、事务
- 单文件超 300 行不拆分
- 中文变量名或拼音变量名
- 改表结构不走迁移
- print 调试遗留
- 伪造测试通过
- 擅自实现 AI 对话逻辑（本期为预留功能，只允许占位与空状态）
- 引入大模型 SDK 或相关依赖
- 代码中出现模型密钥明文
- 在未说明改动文件的情况下直接输出代码
- 把多个原子任务合并成一次交付
- 跳过测试或伪造测试通过
- 使用魔法数字、缩写变量名
- 让函数超过 40 行、文件超过 300 行、嵌套超过 3 层
- 擅自更改已约定的字段名与接口路径
- 在错误代码基础上继续叠加修改，应先回滚或说明修复方案
