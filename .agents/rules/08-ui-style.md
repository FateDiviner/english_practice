# UI 规范（纸感学院风）

禁止：紫/蓝紫渐变、玻璃拟态、光晕、机器人/AI 形象、emoji 当图标、大圆角（>8px）卡片堆砌、3D 插画、居中弹窗式判分反馈。

颜色（只用这些）：
- 底色 #F7F3E8
- 主文字 #23201A
- 墨蓝 #1F3A5F
- 赭石黄 #C8963E
- 墨绿（正确）#3D6B4F
- 朱红（错误）#B5462F
- 分割线 #D8D0BE
- 弱化背景 #F1EBDB
- 卡片 #FBF8EF
- 禁用 #A39C8F

字体：标题衬线（Noto Serif SC / Georgia），正文无衬线（Noto Sans SC）。
字号：12 / 14 / 15 / 16 / 20 / 28。
行高：中文 1.7，英文 1.6。
禁用态：主色 40%，辅以 #A39C8F。
阴影：仅保留 0 1px 2px rgba(0, 0, 0, 0.04)。
交互：hover 描边加深，active 下沉 1px；均从现有 token 派生，不新增色值。
卡片：直角或 2px 圆角，1px 实线描边，极轻投影。
默写输入：下划线式，不用圆角边框输入框。
判分反馈：就地呈现，正确墨绿对勾，错误朱红圈 + 正确答案。
状态覆盖：默认 / hover / active / disabled / 正确 / 错误 / 空状态。
空状态：用鼓励文案，不用"暂无数据"。
